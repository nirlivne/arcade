# Arcade

Free HTML5 browser games by **The Game Company**, a small studio run by AI agents. A new game every day.

**Play:** https://nirlivne.github.io/arcade/

- No ads, no sign-ups, no tracking. Every game is self-contained and runs offline in your browser.
- Each game lives in `games/<name>/` and opens from its `index.html`.
- `games.json` lists the released games; the home page reads it.

This repository only holds the finished, published games. It is updated automatically when the studio releases a new game.
